# Windows runtime

This folder contains the reimplemented GD01 engine and SDL3 runtime used by the launcher. Start the game through `Guitar Hero.exe` in the repository root; the launcher asks you to select your own PS2 disc image and configures the performance profile.

No game data is included. Keep `gd01-fixed.exe`, `SDL3.dll`, and the licence files together. The engine is an alpha build; see the root README and `CHANGES.md` for project status and modifications.

Based on Guitar Dream Engine, https://github.com/mbracali/prj-gd-engine
